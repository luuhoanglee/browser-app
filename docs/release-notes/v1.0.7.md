# Pardix v1.0.7 (versionCode 12)

## What's new — Play Store (Tiếng Việt)

```
• Thêm Bookmarks và Reading List để lưu lại trang yêu thích hoặc đọc sau.
• Sắp xếp trang đã lưu theo thư mục và tìm kiếm nhanh theo tên hoặc địa chỉ.
• Đánh dấu bài trong Reading List là đã đọc hoặc chưa đọc.
• Hỗ trợ nhập và xuất bookmark bằng tệp HTML.
• Tăng cường riêng tư: không lưu bookmark trong chế độ ẩn danh.
```

## What's new — Play Store (English)

```
• Added Bookmarks and Reading List for favorite pages and articles to read later.
• Organize saved pages into folders and quickly search by title or address.
• Mark Reading List entries as read or unread.
• Import and export bookmarks using HTML files.
• Improved privacy: saved pages are disabled in Incognito mode.
```

## Technical changelog

- Added Clean Architecture entity/repository boundaries and `SavedPageBloc`.
- Persisted saved pages through `StorageService` with URL deduplication.
- Added focused-pane integration for normal and split-view browsing.
- Added Netscape bookmark HTML import/export with Pardix metadata.
- Added BLoC, persistence, codec, widget, and toolbar regression tests.
