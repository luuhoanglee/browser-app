# Pardix v1.0.8 (versionCode 13)

## What's new — Play Store

```text
• Added Find in Page, Desktop Site, text zoom and page sharing tools.
• Improved bottom toolbar behavior during scrolling and screen rotation.
• Limited per-tab media resource memory growth.
• Improved recovery of normal browsing tabs after an unexpected exit.
• Added automated release quality checks.
```

## Technical changelog

- Page tools target the focused normal or split-view pane.
- Per-tab resource lists are deduplicated and capped at 200 entries.
- Session checkpoints exclude incognito tabs and use a single JSON snapshot.
- Memory-pressure handling releases background resource lists.
- CI pins Java 17 and Flutter and runs format, analysis and tests.
