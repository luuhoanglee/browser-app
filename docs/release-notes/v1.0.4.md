# Pardix v1.0.4 (versionCode 9)

## What's new — Play Store (Tiếng Việt)

```
• Phát nhiều video cùng lúc: khi chia đôi màn hình, mỗi khung có thể phát âm thanh riêng.
• Vùng trên cùng (status bar) tự đổi màu theo nền trang, nội dung web không còn bị che.
• Sửa lỗi dải trắng dưới thanh địa chỉ khi cuộn ẩn thanh công cụ.
• Gõ tên miền (vd: spacex.com) mở thẳng trang web thay vì tìm kiếm.
• Tối ưu hiệu năng và sửa các lỗi nhỏ.
```

## What's new — Play Store (English)

```
• Play multiple videos at once: in split-screen, each pane can play its own audio.
• The top status-bar area now matches the page's background colour, so content is no longer hidden behind it.
• Fixed the white band under the address bar when the toolbar collapses on scroll.
• Typing a domain (e.g. spacex.com) now opens the site directly instead of searching.
• Performance improvements and minor bug fixes.
```

## Technical changelog

- **feat(tabs) #20** — Play multiple videos simultaneously via a per-pane audio
  owner in split view (`TabBloc`, `webview_page`, `split_audio_toggle`).
- **fix(home) #21** — Collapsed toolbar: the mini URL pill now floats over the
  page content instead of a transparent strip that exposed the white Scaffold
  as a band on dark pages. Only the pill is hit-testable.
- **fix(home)** — Safari-style top safe area: web content is inset below the
  status bar and the strip is painted with the page's own background colour
  (`tabThemeColor`), so no content is clipped under the status bar.
- **fix(search)** — Bare domains (e.g. `spacex.com`) now navigate directly
  instead of triggering a web search; also accepts raw IPv4 hosts.
