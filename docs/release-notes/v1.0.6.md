# Pardix v1.0.6 (versionCode 11)

## What's new — Play Store (Tiếng Việt)

```
• Điều khiển độc lập từng khung khi duyệt web chia đôi màn hình.
• Chạm vào một khung để chuyển thanh địa chỉ, điều hướng, làm mới và thư viện media sang khung đó.
• Kéo để làm mới hoạt động riêng cho từng khung.
• Chuyển đổi tab trong chế độ chia đôi mượt mà hơn, không tải lại trang.
• Cải thiện độ ổn định và sửa các lỗi nhỏ.
```

## What's new — Play Store (English)

```
• Control each pane independently while browsing in split-screen mode.
• Tap a pane to move the address bar, navigation, refresh, and media controls to it.
• Pull-to-refresh now works independently in each pane.
• Smoother split-screen tab switching without reloading pages.
• Stability improvements and minor bug fixes.
```

## Technical changelog

- Added explicit split-pane focus state and events to `TabBloc`.
- Routed toolbar, navigation, progress, search, history, and media actions to
  the focused pane.
- Added per-pane pull-to-refresh controllers and stable WebView keys.
- Improved split-pane selection, swapping, and focus fallback behavior.
- Added focused-pane unit coverage.
